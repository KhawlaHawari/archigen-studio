# Monitoring: Prometheus, Grafana, Evidently, A/B testing

| What | Where | Course item |
| :--- | :--- | :--- |
| Metrics endpoint (technical, model, business) | `GET /metrics` (Prometheus format), code in `src/api/observability.py` | Monitoring: model performance, business metrics |
| Alert thresholds | `monitoring/prometheus/alerts.yml` (7 rules: API down, 5xx rate, p95 latency, drift warning/critical, usable-plan rate, canary behind) | "Définir des seuils d'alerte" |
| Dashboard | `monitoring/grafana/dashboards/archigen.json` (15 panels, generated by `make_dashboard.py`) | Grafana |
| Data drift (in-house) | PSI / KS / Wasserstein, `src/mlops/drift_detector.py`, `GET /monitoring/drift/report` | Drift des données |
| Data drift (Evidently AI) | `src/mlops/evidently_report.py` → `GET /monitoring/drift/evidently` | EvidentlyAI |
| A/B testing / canary | `src/api/ab_testing.py`, decision at `GET /ab/status` | Niveau 2: A/B testing, canary |
| Retraining when drift is detected | `POST /monitoring/drift/retrain` (`src/mlops/continuous_retraining.py`) | Réentraînement déclenché |

## Start the stack
```bash
docker compose up -d archigen-api prometheus grafana
```
- Prometheus: http://localhost:9090 (alerts at **/alerts**). It also scrapes an API running on the host (`host.docker.internal:8000`).
- Grafana: http://localhost:3001 (admin / archigen). The "ArchiGen 3D: production monitoring" dashboard opens by default.

## Generate traffic and drift for a demo
```bash
# a few real plans (each request is counted per model variant)
curl -F "file=@data/raw/external_test_plans/01_clean_bw_cad.png" http://localhost:8000/predict/floorplan/layout
# inject drifted samples (dark-mode plans) -> drift gauges and the drift alerts react
curl -X POST "http://localhost:8000/monitoring/drift/simulate?drift_type=inverted_dark_mode&samples=20"
# Evidently report on the same data
py -3.11 src/mlops/evidently_report.py --domain floorplan     # then open /monitoring/drift/evidently
```

## A/B testing / canary
The champion (Run 3) serves 90 % of plans and the challenger (Run 2) 10 %, sticky per plan (hash of the image).
```bash
ARCHIGEN_AB_CHAMPION=run3 ARCHIGEN_AB_CHALLENGER=run2 ARCHIGEN_AB_CANARY_FRACTION=0.10 uvicorn src.api.main:app
curl -H "X-Model-Variant: run2" -F "file=@plan.png" http://localhost:8000/predict/floorplan/layout   # force a variant
curl http://localhost:8000/ab/status   # usable-plan rate per variant + two-proportion z-test -> promote / keep / rollback
```
`ARCHIGEN_AB_CHALLENGER=none` turns A/B testing off. Promotion = set the challenger as champion
(`scripts/install_run.py`, then re-export ONNX).
